WASM Bundle Failed to Load

The WebAssembly bundle for Keystone could not be loaded. This means the application cannot start.

Possible Causes:

  • The WASM bundle was not built (run trunk build)
  • The web server is not running from the correct directory (must run from web-ui/ directory)
  • The dist/ folder is missing or empty
  • Static file serving is misconfigured

To Fix:

  1. Navigate to the web-ui directory: cd web-ui/
  2. Build the WASM bundle: trunk build
  3. Run the server from the web-ui directory: ../target/release/keystone-web-ui
  4. Or use: just run-web from the repository root

Check the browser console (F12) for additional error details.
